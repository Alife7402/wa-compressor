Tips Optimal Pengunggahan ke WhatsApp Status & Chat

1. Hindari Frame-Drop

WhatsApp memaksa konversi ke 30 FPS secara kasar jika Anda mengunggah video 60 FPS. Menguncinya sendiri dengan x264 menjaga motion blur alami tetap rapi tanpa patah.

2. Flag FastStart MP4

Parameter -movflags +faststart memindahkan metadata MOOV ke bagian awal file sehingga video dapat diputar seketika di WhatsApp tanpa menunggu selesai download.

3. Color Space YUV420p

Encoder kami selalu mengunci format pixel ke YUV420p, memastikan tidak ada layar hitam atau error pemutaran di HP Android versi lama maupun iPhone terbaru.

🚀 Panduan Deploy GitHub Pages (Cross-Origin Isolation)

FFmpeg WebAssembly memerlukan SharedArrayBuffer untuk kompresi video berkecepatan tinggi multi-threading. GitHub Pages tidak mengizinkan kustomisasi HTTP Header server, sehingga trik resmi adalah menggunakan Service Worker (coi-serviceworker.js).

Langkah-langkah di GitHub Repo Anda:
  1. Simpan file ini sebagai index.html pada repository Anda.
  2. Letakkan file coi-serviceworker.js di folder yang sama (root repo).
  3. Aktifkan GitHub Pages dari Settings > Pages > Deploy from Branch (main / root).

Jika file coi-serviceworker.js belum ada, Anda dapat menyalin isinya di bawah ini: 

/*! coi-serviceworker v0.1.7 - MIT */
