Fitur Utama: Pertahankan Resolusi 100% & Kualitas Visual

Mode ini tidak mengubah resolusi piksel asli dan mempertahankan ketajaman gambar tinggi, hanya mengurangi jumlah bingkai per detik (FPS). Sangat efektif menghemat ukuran hingga 40% - 70% untuk video presentasi, tutorial layar, webinar, vlog berbicara, dan video dengan sedikit gerakan cepat.

Mode Seimbang: Mengoptimalkan resolusi hingga maksimal 720p/1080p, menurunkan FPS ke 24 FPS, dan menerapkan bitrate standar menengah agar video tetap enak ditonton di berbagai perangkat dengan ukuran yang pas.
Mode Kompresi Maksimal: Mengubah resolusi ke 480p, FPS ke 15 FPS, dan bitrate rendah. Sangat cocok jika Anda ingin mengirim video lewat WhatsApp, Discord tanpa Nitro, email, atau kuota hemat.

Panduan Deploy ke GitHub Pages

Gratis seumur hidup, tanpa sewa hosting atau server

1
Ekstrak File ZIP

Ekstrak file ZIP yang sudah diunduh. Anda akan menemukan file index.html dan README.md.

2
Buat Repository Baru di GitHub

Buka github.com/new, beri nama repository (misal: video-compressor), set Public, lalu klik Create repository.

3
Upload File ke Repository

Pilih opsi "uploading an existing file" di GitHub, tarik file index.html ke repository, lalu klik Commit changes.

4
Aktifkan GitHub Pages

Buka menu Settings di repository → klik tab Pages di sisi kiri → pada bagian Branch, pilih main dan folder / (root) → klik Save.

🎉 Selesai! Dalam 1-2 menit, website kompresor video Anda sudah live di URL: https://username.github.io/video-compressor/ dan bisa diakses dari HP, laptop, maupun desktop mana saja!
